Codes sources des composants libres

Kakapoted Studio lance FFmpeg 8.1 comme programme séparé (dossier ffmpeg du logiciel), sous licence GNU GPL v3. Conformément à cette licence, voici son code source et de quoi reconstruire exactement la version livrée.

  • ffmpeg-8.1-source.tar.xz — code source de FFmpeg 8.1 (étiquette n8.1).
  • ffmpeg-builds-recette.tar.gz — recette de construction Windows (BtbN/FFmpeg-Builds) : scripts et correctifs utilisés.
  • bibliotheques.txt — liste des bibliothèques incluses dans FFmpeg, avec l'adresse de leur dépôt et la version exacte.

Kakapoted Studio lance aussi eSpeak NG 1.52 comme programme séparé (dossier espeak-ng du logiciel, prononciation des voix naturelles), sous licence GNU GPL v3 ou ultérieure. Code source exact et recette de construction :

  • espeak-ng-1.52.0-source.tar.gz — code source d'eSpeak NG 1.52.0 utilisé, sans modification (SHA-256 d2a886bae3547a15c52801cb37e415230834a7ee7f9a57352b98d60454d97cea).
  • espeak-ng-recette-build.mjs — recette de construction (MinGW-w64, options et langues incluses).

Les autres composants (bibliothèques MIT, BSD, Apache…, polices) sont listés avec leurs licences dans le fichier LICENCES-TIERS.txt du dossier d'installation. Pour toute demande de code source : passez par la page d'accueil du site.

English: source code of the free components shipped with Kakapoted Studio (FFmpeg 8.1 and eSpeak NG 1.52, GPL v3), their Windows build recipes and the exact versions of the libraries it includes.
